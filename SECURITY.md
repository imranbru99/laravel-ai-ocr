# Security policy

Report security issues privately to **me@imrandev.bd**. Do not disclose documents,
credentials or an exploit payload in a public issue. Include affected versions,
a minimal synthetic reproduction and the expected trust boundary.

The package treats documents, URLs, archives, filenames and model output as
untrusted. See docs/security.md for the threat model and deployment requirements.
The current development version has no stable security support window; releases
will use semantic versioning and document fixes in CHANGELOG.md.
